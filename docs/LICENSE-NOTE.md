# Licence note

**Status: placeholder. The licence-note wording has not been reviewed by counsel and must not be relied on as legal advice or as a legal conclusion.** QuietVote is an unaudited prototype and is not for real elections.

## What this file must hold

[QV-25](25-legal-compliance-licensing.md) section 3.2 says that documentation is licensed CC BY-SA 4.0 and that **code in docs** (snippets, pseudocode, schemas) is intended to be dual-licensed, CC BY-SA 4.0 and AGPL-3.0-or-later with the reader free to choose, and that this is to be recorded in `docs/LICENSE-NOTE.md`. The specification itself marks the validity and workability of that dual-licensing text as needing counsel confirmation, and marks AGPL-3.0 compatibility with CC BY-SA 4.0 as unverified.

## What is true today

- The repository [LICENSE](../LICENSE) file is the GNU Affero General Public License version 3.
- The specifications describe documentation as CC BY-SA 4.0 and code in docs as dual-licensed (QV-25 section 3.2; decision ADR-011 in [decision-log.md](decision-log.md)).
- No reviewed licence-note text exists. This file does not state a licence grant, does not interpret either licence, and does not conclude that the dual-licensing arrangement is valid.
- Contribution terms (DCO sign-off, no CLA) are in [CONTRIBUTING.md](../CONTRIBUTING.md); the policy for pseudonymous contributors is an open question (QV-OQ-25-2) that needs counsel input.
