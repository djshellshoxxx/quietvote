## What independent recount/verification is actually possible today

Facts from source and one run each of the Python vector sweep and the comparator on this snapshot.

TS verifier (`packages/verifier`): loads a strict-JSON election bundle (closed members), runs `protocol.verifyElection` (manifest hash and signature, trustee keys, ballots, latest-ballot rule, aggregate recompute, decryption proofs, result rules, Benaloh spoils, encoding, time window) and, when the bundle has a `board` member, `board.verifyLog` (tree, checkpoints, cosignatures, grammar, receipts, forks). It reports V1..V14, verdict PASS/FAIL/INCOMPLETE, a `reportHash`, and a self-test over a corpus (control, canary, mutants, synthetic hostile input). Exit codes: 0, 1, 2, 3, 4. V13 is always `not_run`. Without a board export, V4 is `not_run` but the verdict can still be PASS (open decision P1/TSV-05). Unless a manifest hash is supplied out of band, a caveat is printed. Witness identities come from the bundle (self-attested). It reads JSON bundles, not the `.qvb` tar.

Python verifier (`verifier-py`): standard library only. Vector sweep on this snapshot: 282 total, 229 PASS, 0 FAIL, 53 NOT-IMPLEMENTED (48 `log.verify_election`, 5 `benaloh.private_audit`). It verifies full election bundles but never examines a board export: `chk.board.*` and `chk.receipts.sample` are `not_run`. No INCOMPLETE verdict (D-96), no trustee-mode spoil (D-95), no adapter protocol, no CI import scan. Unaudited; independence not claimed.

Strict comparator (`scripts/compare-verifiers.ts`): runs both verifiers over every election, mutation and the canary (27 cases). It compares verdict, every TS check except `chk.board.append_only`, `chk.board.witness` and `chk.receipts.sample`, `counts.cast/spoiled/counted`, `ctx_prefix`, and `results`. It excludes the three log-layer checks, findings/codes, notes, other counts, `reportHash`, and anything about the log layer. Result on this snapshot: 24 of 27 agree, 3 disagree (`manifest-signature-removed`, `count-altered`, `result-flipped`; D-92, D-93, D-94), verdicts agree 27 of 27, exit 1 by design. Agreement is not a security claim.

Consequence: a third party can recompute tallies and check ballots, proofs and results with two codebases, but only the TS verifier checks the log, and its witness evidence is not independently confirmed.
