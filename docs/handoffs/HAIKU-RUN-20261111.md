## 6. Backlog (priority order: security first, then function, then risk)

Security-relevant:
- **B-1 (high):** `packages/trustee/src/cli.ts` `parseArgs` still echoes a positional value in its "unexpected argument" error. A passphrase typed as a positional would be echoed. Fix: never echo positional values. Add a test.
- **B-2 (medium):** `keystore.ts` KDF cost confirmation is opt-in: `defaultDeps()` does not set `confirmCost`, so a future caller can skip the prompt. Make the confirmation required, with a test.
- **B-3 (low, caveat from L2):** the KEK guard reads `control.sqlite` read-only and throws on a database without the schema. This fails closed (no key replaced), but gives a confusing error. The normal startup path migrates the database first, so it is not reached in practice. Improve the message; do not treat "no such table" as "no data".
- **B-4 (medium, caveat from L3):** deletion now opens the election before deleting. A corrupt election database therefore blocks its own deletion, which it did not before. The admin DELETE route still pre-checks the registry. Decide whether a corrupt election must be deletable, and test it.
- **B-6 (low):** `scripts/check-deps.mjs` skips symlinked source files, so they never reach the layering scan.

Function and policy:
- **B-5:** product review of the alarm-state copy from L4. It now offers "Save receipt" on an integrity-failure view.
- **B-7:** `claims-lint.yml` runs `trace.mjs --check` as a blocking gate, but commit `80c3a17` describes trace as report-only. Resolve the mismatch.
- **B-8:** L1's allowlist is global, so `status --out F` is accepted and ignored. Add per-command validation.
- **B-9:** `scripts/deps-known-deviations.json` D-97 accepts an upward `protocol -> board` edge. Owner decision.
- **B-10:** PR #27 gaps: `07fd61c` (export `acknowledged_at`, IPv6 /56 buckets), `80c3a17` (CLAIMS-LINT-HISTORICAL markers). Each needs owner review first where it touches section 4 items.

Not started (from the completion handoff section 6): OPS-A server launcher and `deploy/`, OPS-B data-directory lock and offline backup verify/restore, CLI-ONLINE organizer commands, CORE-A witness options, CORE-B marker equivocation, SRV-A/B (partly done here), TRU-A (partly done here), WEB-A/B/C (partly done here), TEST-A/B, the cross-package E2E in section 3.3 of the completion handoff, and the performance measurement of the tally.
