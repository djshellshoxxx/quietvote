# Accessibility and Help

QuietVote is draft, unaudited software and is not for real elections. The guidance here describes available help and settings; it is not a claim that the product has passed a full accessibility audit or meets every accessibility requirement.

## Open Help

Open the `/help` route (type it in the address bar after the site address, or use the Help link shown in the app). The page includes keyboard and screen-reader guidance, display settings, and instructions for reporting a problem. Existing report instructions remain available there.

## Keyboard use

- Press **Tab** to move forward through controls and **Shift+Tab** to move backward.
- Press **Enter** or **Space** to activate a button or control.
- In an option group, use the **arrow keys** to move between choices.

## Display settings

In Help, use **Colour theme** to choose **Follow my device**, **Light**, or **Dark**. Follow my device uses your operating system’s colour preference automatically. You can also turn on **High contrast** for stronger text and borders. High contrast overrides the selected palette while it is on; switch it off to return to the selected palette.

These choices are kept only for the current page session. Returning to Help during that session restores the current choices. A full page reload starts again with the device defaults.
