**Status:** empty state (QV-ADR-027 N-08b, 2026-11-04). QuietVote is unaudited and not for real elections.

This file is required by [QV-27-REQ-001](docs/27-project-governance-release.md) and is described in [docs/27 §5.2](docs/27-project-governance-release.md#52-structure). It lists people only after they have been appointed through the process in docs/27 §5.1. Nobody has been appointed yet, so the lists below are empty. Nothing in this file is a placeholder for a real person.

- **Repository owner during bootstrap:** the single placeholder owner listed in [.github/CODEOWNERS](.github/CODEOWNERS). That file says it must be replaced with real maintainers and security-reviewer groups before code-owner review is enabled.

## Format once people are appointed

Each entry will give: a persistent name or pseudonym, a contact address, role(s), the packages owned, a voluntarily declared affiliation (employer affiliations of maintainers must be disclosed, docs/27 §5.2), the date appointed, and the fingerprint of any registered release key (which must also appear in docs/RELEASE-KEYS.md). Entries are added only by the docs/27 §5.1 process, and inactive maintainers move to an emeritus list (§5.5).
