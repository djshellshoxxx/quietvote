# Code of Conduct

QuietVote is for voluntary groups that make decisions together. This project should be a place where people can disagree on technical and governance questions without fear of harassment.

## Expected behaviour

- Assume good faith and explain your reasoning, especially on security and cryptography questions.
- Keep discussion about the work, not about people.
- Respect privacy: do not publish other people's personal data, ballots, or private messages.
- Report security issues privately (see [SECURITY.md](SECURITY.md)), not in public issues.

## Unacceptable behaviour

- Harassment, threats, or discrimination based on identity or background.
- Publishing private information about someone without consent.
- Deliberately misleading others about security, privacy, or election-integrity guarantees.

## Reporting

Report concerns to the maintainers through the private reporting channel described in [SECURITY.md](SECURITY.md). Reports are handled confidentially. Maintainers will acknowledge a report, review it, and decide on a response, which may range from a private warning to removal from project spaces.

## Scope

This code applies to project spaces (repository, issues, pull requests, discussions) and to participation in project activity.

## Status

This is a short initial text. Maintainers may revise it through the process in [GOVERNANCE.md](GOVERNANCE.md).
